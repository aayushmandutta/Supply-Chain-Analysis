# Supply Chain Analysis & Power BI Dashboard

Supply chain analytics project developed using **Power BI and DAX** to analyze revenue, suppliers, inventory, transportation, manufacturing, and product quality.

## Tools
- Power BI
- DAX
- Data Cleaning
- Data Visualization

## Key Analysis
- Revenue & product category analysis
- Supplier lead time & defect rate
- Transportation & route costs
- Inventory vs sales
- Manufacturing cost & production volume
- Quality inspection analysis

## Key Outcome
Developed an interactive dashboard to identify supply chain inefficiencies and provide data-driven recommendations for improving operational performance.
